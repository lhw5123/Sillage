# Sillage

This is a MacOS Desktop App (Only support ARM64 for now). It developed by Rust and [GPUI Component](https://github.com/longbridge/gpui-component).

The base features:

1. It can interact with user's local coding agents: Claude Code, Codex CLI, Cursor CLI, DeepSeek Harness.
    Sillage can detect which agent CLIs installed on the computer when it launched.
2. The App page should follow the below image.
    "/Users/hevin/Library/Application\ Support/CleanShot/media/media_tDjLkec4Kt/CleanShot\ 2026-08-27\ at\ <15.28.08@2x.png>"
3. 全局快捷键遵循 NeoVim 的规则。例如：
    - 双击 Esc 后，进入 command 模式，点击 f 后，全局展示可以点击的地方，类似于 Chrome 上 Vimium 插件的效果。
